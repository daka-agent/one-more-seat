# 留一副碗筷

一张永远留着空位的桌子。为不在场的人摆一副碗筷，留一句话。

起因是电影《欢迎来龙餐馆》。徐福什么大事都没做成——他没能阻止战争，也没能救下所有人，从头到尾只做了一件事：让眼前这个人吃上一顿热饭。

## 它是怎么运作的

- 打开时桌上已经坐着五个人，说的话全部来自可核实的公开材料（联合国儿童基金会、世界粮食计划署、影片台词、导演自述），不是网友留言
- 你选那个空着的位子坐下，可以写一句话，也可以什么都不写
- 十位坐满，再开一桌
- 你摆过的碗筷只存在这台设备上（localStorage），不上传，也没有人能看见

## 几条自己定的规矩

- 不排行、不计数、不比谁写得好
- 不显示"总共有多少人参与"
- 不接后端，不做留言板，因此也没有审核和脏话的问题
- 桌上那句诚实的话必须留着：这一副碗筷救不了任何一个孩子，它只是让你和我记住还有人没有这张桌子

## 技术

单文件静态页面，无构建、无依赖、无后端。直接用浏览器打开 `index.html` 即可。
