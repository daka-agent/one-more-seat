# 留一副碗筷

一张永远留着空位的桌子。点一道菜，菜会端到中间的转盘上。

起因是电影《欢迎来龙餐馆》。徐福什么大事都没做成——他没能阻止战争，也没能救下所有人，从头到尾只做了一件事：让眼前这个人吃上一顿热饭。

## 它是怎么运作的

- 桌子中间有一个转盘，转盘上摆着这一桌点过的菜
- 桌上已经坐着五位，他们各点了一道，转盘上那五盘是他们的
- 你的位子在正下方，会轻轻呼吸。点菜单上任意一道菜，可以留一句话，也可以什么都不写
- 菜端上来时会冒一口气落在转盘上，你点的那盘碗沿留一圈颜色，认得出是自己端的
- 你的碗筷旁边印着菜名，你写的那句话常驻在桌面下方，不再藏起来
- 页面底部有一本流水，记着你端上桌的每一道菜、哪天、写了什么
- 十位坐满，转盘收起来重新开一桌

## 菜单

六道菜，每一道都对着影片里的一场戏：

| 菜 | 出处 |
|---|---|
| 饺子 | 上车饺子。出发那天，母亲从锅里夹给他的那一个 |
| 一碗面 | 下车面。回来那天，女儿端来的那一碗 |
| 徐福烩饭 | 半个煤气罐架起的锅，逃亡路上围着二十三个孩子 |
| 荷包蛋 | 每个孩子被送走之前的最后一餐。鸡蛋不够了 |
| 番茄汤 | 他把该是辣椒水的东西，偷偷换成了番茄汤 |
| 发芽土豆炖牛肉 | 故意做的。孩子拉肚子，就能多留一天 |

菜单上每一栏都是 ¥1.8。这不是玩笑——约 ¥1.8，是一个孩子在另一个地方吃一顿校餐的钱（世界粮食计划署数据）。

## 几条自己定的规矩

- 不排行、不计数、不比谁写得好
- 不显示"总共有多少人参与"
- 不接后端，不做留言板，因此也没有审核和脏话的问题
- 你点过的菜只存在这台设备上（localStorage），不上传
- 桌上那句诚实的话必须留着：这一桌菜救不了任何一个孩子，它只是让你和我记住还有人没有这张桌子

## 技术

单文件静态页面，无构建、无依赖、无后端。直接用浏览器打开 `index.html` 即可。
