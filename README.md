# 留一副碗筷 · 好好吃饭

一张永远留着空位的桌子。请一个人坐下，点一道这个人爱吃的，再留一句话。来不了，位子也留着。

作品名是「留一副碗筷」，标题下那行字是「好好吃饭」——**前者是你做的事，后者是你说的话**，缺一个都不完整。

**在线地址：https://daka-agent.github.io/one-more-seat/**
源码：https://github.com/daka-agent/one-more-seat

起因是电影《欢迎来龙餐馆》。徐福没能阻止战争，也没能救下所有人。他从头到尾只做了一件事——让眼前这个人吃上一顿热饭。就这样，二十三个孩子活了下来。

## 它是怎么运作的

- 徐福坐在主位。开餐馆的请客，天经地义——你请的人，都由他来做
- 点一个空位（或按「请一个人坐下」），写下名字，这个人就坐下
- 坐下时要选一件事：**还会来**，还是**来不了了**
- 然后点一道这个人爱吃的。菜落到中间的转盘上，就摆在面前
- 请的时候可以留一句话。**留言框里默认就写着「好好吃饭」**——不知道写什么，就留这四个字
- 菜端上来会冒一口气；这副碗筷旁边印着菜名
- 九位坐满，再开一桌；上一桌的人仍然留在流水里

### 来不了了

这是这一版最重要的一个决定，**大卡拍板允许**。

你可以请一个再也来不了的人坐下。这副碗筷和别人一样盛着饭——不标注，不特别对待。唯一的区别是：

- **还在的人**，你会拿到一张卡片，一句话加一个链接，可以真的发过去。对方打开，就能看见你留的这副碗筷
- **来不了的人**，那句话只能留在这张桌子上。没有链接，也发不出去

「留一副碗筷」的全部含义，就在于那个位子本该是空的。人要是真来了，就不用留了。

## 桌上的规矩：碗在左，筷在右

每个位子面前摆的是**一整套**餐具，不是一只碗加一双筷子：

| 位置 | 餐具 |
|---|---|
| 骨碟正上方（靠桌心） | 茶杯 |
| 骨碟左上 | 饭碗，碗里盛着饭 |
| 骨碟右上 | 味碟，碟里有蘸酱 |
| 正中偏下（靠客人） | 骨碟 |
| 骨碟右侧 | 筷架，一双筷子架在上面 |

三条必须守住的：

1. **筷子不碰碗。** 筷子斜搭在碗上叫"横担"，供神祭祖才这么摆；插进饭里是灵前的"供筷"。两个动作都是祭奠的姿态——而这部片子讲的恰恰相反，是让活着的人吃上一顿热饭
2. **碗在左，筷在右。** 每位客人的餐具整体跟着座次旋转，所以从任何一个角度看，饭碗都在各自的左手边
3. 参照中餐宴会摆台标准简化：宴席上骨碟距桌边 1.5 厘米、汤碗与味碟各距 1 厘米，页面按俯视比例缩放

三种状态也是三种餐具：已坐的人是实心白瓷、碗里有饭（来不了的人瓷色略淡一号，其余完全相同）；空位是灰色虚线轮廓——**那是一套还没摆出来的餐具**，不是一个圆圈。

## 菜单

34 道菜，**菜名全部出自影片《欢迎来龙餐馆》**，分七组：镇店、热菜、家常、凉菜、宴席、小吃与甜品、片尾。

规矩只有一条：**有明确场次的，写那一场戏；只在银幕上一闪而过的，只写它是什么菜——不编情节。** 比如：

| 菜 | 出处 |
|---|---|
| 龙抬头 | 松鼠鳜鱼改的。他刚开店的镇场菜，也是他不肯做左宗棠鸡的底气 |
| 徐福烩饭 | 半个煤气罐架起的锅，逃亡路上围着二十三个孩子 |
| 铁锅炖烤鱼 | 婚宴上，东北铁锅炖遇上阿拉伯烤鱼。他第一次和当地人打成一片 |
| 土豆炖牛肉 | 「张嘴」。他让俊生尝的第一口 |
| 发芽土豆炖牛肉 | 还是这一道，这次故意做坏：孩子拉肚子，就能多留一天 |
| 荷包蛋 | 每个孩子被送走之前的最后一餐。鸡蛋不够了 |
| 番茄汤 | 他把该是辣椒水的东西，偷偷换成了番茄汤 |
| 青苔面 | 片尾菜单上闪过的名字。真事：贝鲁特港大爆炸后，废墟旁一家中餐馆免费煮面，只换客人讲一件开心的事 |

剧组前后研发了约 140 道菜（凉菜 23 道、热菜 80 道），呈现在银幕上的近 40 道，这里收了 34 道。

**关于价格**：片尾那张菜单上标的是当地货币。换了六种检索角度，没有任何公开来源记录过那些数字，所以这一页**不出现影片里的菜价**。价格栏沿用 US$0.25 那把尺子。

菜单上每一栏都写着 US$0.25。这不是玩笑——世界粮食计划署的口径是：一份校园餐平均约 0.25 美元，50 美元供一个孩子吃一整学年。

这一栏不是售价。页面不收任何钱，也不代为捐赠。要注意的是：**0.25 美元这个数是 WFP 的原始数据，任何换算成人民币的版本都不是**——汇率一动它就漂，而且各国各项目的实际成本差异很大。

## 几条自己定的规矩

- 不排行、不计数、不比谁写得好
- 不显示"总共有多少人参与"
- 不接后端，不做留言板，因此也没有审核和脏话的问题
- 你点过的菜只存在这台设备上（localStorage），不上传
- 桌上那句诚实的话必须留着：这一桌菜救不了任何一个孩子，它只是让你和我记住还有人没有这张桌子

## 递出去的那句话

还在的人，页面上会生成一张卡片，内容是一句话加一个链接：

```
妈，我给你留了副碗筷。替你点了饺子。「好好吃饭」
https://daka-agent.github.io/one-more-seat/?to=妈&msg=好好吃饭&dish=饺子
```

复制下来，发微信、发短信都行。对方打开链接，页面顶部会出现一张卡片：「小宝，这句话是留给你的。替你点了饺子。」

**不需要后端。** 全部信息都在 URL 参数里，纯静态就能做到。软件不替你做那件最难的事——开口说这句话——它只是把这句话变得好说出口。

## 技术

单文件静态页面，无构建、无依赖、无后端。直接用浏览器打开 `index.html` 即可。

- 数据存在 `localStorage` 的 `liuyifuwankuai.v3`，结构是 `{v:3, guests:[{name, kind, msg, at, table, slot, dishes}]}`
- `kind` 只有两个值：`invited`（还会来）和 `kept`（来不了了）
- 十人一桌：slot 0 固定是徐福，1–9 是你请的人；坐满九位再请人，自动开下一桌
- URL 参数 `to` / `msg` / `dish` 用于被邀请的人打开页面；点「我也摆一副碗筷」后 `history.replaceState` 清掉参数，不留痕
